## העלאה ל-GitHub Pages

1. צור Repository חדש
1. העלה את **כל** הקבצים (כולל `mathapp-shared.js`!)
1. **Settings → Pages → Branch: main → Save**
1. האתר יהיה זמין בכתובת: `https://USERNAME.github.io/REPO-NAME/`
